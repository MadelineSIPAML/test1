# Biblioteca App

## Descripción
La Biblioteca App es una aplicación web diseñada para gestionar una biblioteca. Permite a los usuarios agregar, eliminar y visualizar libros de manera sencilla y eficiente.

## Estructura del Proyecto
El proyecto contiene los siguientes archivos:

- `src/index.html`: Página principal de la aplicación con la estructura HTML básica.
- `src/styles/style.css`: Archivo de estilos CSS que define el diseño visual de la aplicación.
- `src/scripts/app.js`: Archivo JavaScript que maneja la lógica de la aplicación y la interacción del usuario.

## Instalación
Para instalar y ejecutar la aplicación, sigue estos pasos:

1. Clona el repositorio:
   ```
   git clone <URL del repositorio>
   ```

2. Navega al directorio del proyecto:
   ```
   cd biblioteca-app
   ```

3. Abre el archivo `index.html` en tu navegador.

## Características
- Agregar libros a la biblioteca.
- Eliminar libros de la biblioteca.
- Visualizar la lista de libros disponibles.
